Infra Abogados – Prueba de API

Esta página te permite probar la API desplegada en AWS: healthcheck, consultas de audiencias y creación/cancelación de audiencias usando Cognito para autenticación.

1. Endpoint base de la API

Usa aquí el api_endpoint de Terraform, por ejemplo: https://9jw1npwoqk.execute-api.us-east-1.amazonaws.com/dev.

Puedes cambiarlo si más adelante tienes un entorno prod.

2. Token JWT de Cognito

Inicia sesión en Cognito (o registra un usuario) y pega aquí el Access Token o Id Token para probar los endpoints protegidos (/audiencias, /reportes, etc.).

El backend espera el header Authorization: Bearer <token>.

 (demo: configura la URL real del Hosted UI en config.js).

3. Pruebas rápidas

/health es público (sin token). /audiencias requiere JWT de Cognito con el rol adecuado.

Si el token no es válido o el rol no tiene permiso, el backend devolverá 403 o 401.

4. Mini UI – Audiencias por rol

Selecciona el rol del usuario con el que has iniciado sesión. Esta selección solo afecta a cómo se muestra la interfaz; las restricciones reales se aplican en el backend usando los grupos de Cognito (ADMINISTRADOR, SECRETARIA, ABOGADO).

4.1. Consultar audiencias visibles

Según el rol: ADMINISTRADOR ve todas, SECRETARIA ve las de sus abogados asignados, ABOGADO solo las suyas.

4.2. Crear audiencia ADMINISTRADOR / SECRETARIA

El backend validará permisos. Si iniciaste sesión como ABOGADO, esta operación debería fallar con 403.

Se enviará como ISO (ej. 2025-12-01T09:00:00Z).

4.3. Cancelar audiencia ADMINISTRADOR / SECRETARIA

Esta operación realiza un soft delete marcando la audiencia como CANCELADA.
