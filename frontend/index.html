Infra Abogados – Demo de API por rol

Esta página te permite probar el flujo completo: login en Cognito, obtención del JWT y llamadas a la API de audiencias según el rol: ADMINISTRADOR: todo SECRETARIA: CRUD de sus abogados ABOGADO: consulta / reporte

1. Endpoint base de la API

Usa aquí el api_endpoint de Terraform. Para HTTP API con stage dev, normalmente será algo como: https://9jw1npwoqk.execute-api.us-east-1.amazonaws.com/dev.

Puedes cambiarlo si más adelante tienes otros entornos.
La UI añadirá automáticamente /health, /audiencias, etc.

2. Login en Cognito y obtención de JWT

1) Haz clic en el botón de abajo para abrir el Hosted UI de Cognito.
2) Inicia sesión con un usuario configurado en tu User Pool.
3) Cognito redirige a este mismo sitio con el token en la URL.

El backend espera el header: Authorization: Bearer <token>.
Si vienes del callback de Cognito, la página intentará extraer el token automáticamente de la URL.

5. Operaciones por rol sobre audiencias


    
    

      
5.1. Consultar audiencias visibles

      

        Según el rol:
        ADMINISTRADOR ve todas,
        SECRETARIA ve las de sus abogados asignados
        (claim custom:abogados_asignados),
        ABOGADO ve solo las suyas.
      

      
    


    
    

      

        5.2. Crear audiencia
        ADMINISTRADOR / SECRETARIA
      

      

        El backend valida permisos con los grupos de Cognito. Si el token pertenece a un
        ABOGADO, esta operación debe responder 403.

        5.3. Cancelar audiencia (soft delete)
        ADMINISTRADOR / SECRETARIA
      

      

        Marca la audiencia como CANCELADA sin borrarla físicamente.
      


      
      

      
    


    
    

      
5.4. Reporte del ABOGADO

      

        Para el rol ABOGADO, desde esta página la validación se centra en:
        
• Ver que GET /audiencias solo devuelve sus propias audiencias.

        • Ver que los intentos de crear o cancelar audiencias
        responden 403 (no autorizado).

        La lógica de reporte detallado (por ejemplo, generar documentos o estadísticas)
        se implementa en la Lambda de reportes (/reportes).
