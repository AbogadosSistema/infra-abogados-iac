Infra Abogados – Prueba de API

Esta página sirve para probar rápidamente la API desplegada en AWS: healthcheck, consultas de audiencias y creación de audiencias usando Cognito.

1. Endpoint base de la API

Puedes ajustar la URL si cambias de entorno (dev, prod, etc.).

2. Token JWT de Cognito

Pega aquí el Access Token o Id Token de Cognito para probar los endpoints protegidos (/audiencias, /reportes, etc.).

3. Pruebas rápidas

/health es público (sin token). /audiencias requiere JWT de Cognito con el rol adecuado.

4. Mini UI – Audiencias

Usa este formulario para crear una audiencia de prueba (POST /audiencias) y listar las audiencias visibles según tu rol (GET /audiencias).
